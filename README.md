# Seminar-Management-System (JAVA Swing)
OOAD Lab Practice.

This repository contains a Java Swing–based Seminar Management System developed as part of the CCP6224 Object-Oriented Analysis and Design Lab Exercise. The system is designed to support the management of a Postgraduate Academic Research Seminar, functioning as a mini-conference platform for master’s and PhD students.

The application follows object-oriented design principles, with clear separation between model, controller, and user interface layers, and includes comprehensive UML documentation (class and sequence diagrams) to ensure strong design coherence between analysis and implementation.

##Key Features

- Role-based user management for Students, Evaluators, and Coordinators

- Student module for seminar registration, presentation type selection, and material upload

- Evaluator module for rubric-based assessment and feedback

- Coordinator module for session creation, assignment of presenters and evaluators, and report generation

- Seminar scheduling and evaluation reporting

- Award computation for Best Oral, Best Poster, and People’s Choice

##Technical Highlights

- Implemented using Java Swing (standalone desktop application)

- UML-driven design with inheritance, encapsulation, and polymorphism

- Controller-based workflow aligned with sequence diagrams

- Modular, extensible architecture suitable for future enhancements

##Academic Context

- This project is developed as a group-based OOAD exercise, emphasizing:

- Proper task delegation and modular design

- Alignment between UML diagrams and code

- Individual accountability during presentation and evaluation
